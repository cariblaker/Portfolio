# Junior Project Smart Stepper

> Weekly updates of progress so as not to lose it!

## Description

The SmartStepper reads in data from sensors in a shoe, and outputs via bluetooth information about toe strikes vs heel strikes, to be used by several apps to encourage children to heel strike.

## Getting Started
Follow directions here: https://wiki.seeedstudio.com/XIAO_BLE/ to setup dev environment for the Seeed Sense board

Also to read data from the device over BLE, i am using the "Bluefruit Connect" app on my phone. Looks like its available on Android and Apple
